# ADR 0002：永久迁移协调器与可删除的 v1.15 适配器

日期：2026-07-11
状态：已接受

## 背景

原迁移服务同时解释 1.15 数据、持久化报告、控制写门禁并绘制设置 UI。若整体作为兼容层删除，未来迁移会重新实现事务和门禁；若整体保留，1.15 格式依赖又无法在 1.17 清除。

## 决策

保留不解释具体旧格式的 `MigrationCoordinator`，由它管理显式源/目标、报告和写门禁。1.16 的 `V15MigrationAdapter` 通过回调接入，只读解析由 `LegacyMineBackup15Reader` 完成，UI 只消费报告模型。关闭迁移编译开关时，adapter 和 reader 源文件不进入任何目标。

## 结果

1.17 可删除 v1.15 adapter、reader 和旧远端 INI 入口而保留通用迁移能力。协调器接口需要保持格式中立；任何新旧格式解析都必须位于可替换适配器中。
