# ADR 0003：以 AppPaths 定义配置档边界

日期：2026-07-11
状态：已接受

## 背景

配置、历史、迁移报告、日志和临时文件曾依赖进程当前工作目录，导致快捷方式、自启动、终端和 `.app` 启动得到不同数据，并可能写入只读安装目录。

## 决策

启动按 `--data-dir > portable.flag > 平台默认` 解析一次绝对 `AppPaths`。配置、数据、状态、缓存、runtime、工具、只读资源和日志使用独立根；配置档身份来自规范化 configRoot。Windows 和 AppImage 可用相邻 marker 进入便携模式，macOS 始终把用户数据放在用户 Library。应用不再改变当前工作目录。

## 结果

同一配置档从任意工作目录启动都访问相同数据，不同显式配置档可隔离运行。无效显式目录必须报错，不能回退；安装包和 `.app` 内只保留只读资源。后续单实例、位置发现和迁移都以配置档身份与绝对路径为输入。
